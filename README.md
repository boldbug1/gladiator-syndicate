# Gladiator Syndicate

A 2D platformer built with Godot 4.7.

## Getting Started

1. Open the project in Godot 4.7+
2. The main scene is `scenes/main.tscn`
3. Run the project (F5)

## Project Structure

| Path | Description |
|------|-------------|
| `scenes/player.tscn` | Player character |
| `scenes/platform.tscn` | Platform environment |
| `scenes/enemy.tscn` | Enemy entities |
| `scenes/ui.tscn` | UI elements |
| `scenes/main.tscn` | Main scene (root) |
| `assets/` | Art, audio, and other resources |
